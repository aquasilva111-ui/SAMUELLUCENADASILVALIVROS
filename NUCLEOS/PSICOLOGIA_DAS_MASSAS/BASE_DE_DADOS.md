# Base de dados — Núcleo Psicologia das Massas
**Update:** 2026-10-16

## Entidades de base
- COLECAO: identificador, título editorial, frase autoral, data de decisão, natureza, status, direção editorial.
- OBRA_HISTORICA: autor normalizado, título original, edição princeps, idioma, direitos e referências.
- EDICAO: exemplar-base, editor, ano, variantes, digitalização, imagem, licença.
- TRADUCAO: tradutor, idioma, versão, matriz de trechos, decisões lexicais, direitos.
- PARATEXTO: autor próprio, tipo, data, tese, referência às fontes.
- CONVENCAO: grupo/pessoa/ator, enunciado, sete núcleos, fontes, temporalidade, grau de confirmação.
- BEAT_EDITORIAL: ID estável, fundamento pregresso, função, ligação a obra e paratexto, status.
- ASSET: arquivo, autor, licença, prompt, data, estado de aprovação.
- EVENTO_DECISAO: data, fala literal, unidades extraídas, alteração, autor aprovador.
- LACUNA: questão, dependência, impacto e status.
