# Core Visions — Metodologia Editorial Operacional

**Origem documental:** 14/04/2026  
**Última atualização desta implementação:** 2026-10-16  
**Status:** metodologia transversal; aplicar somente aos livros que Samuel identificar como pertencentes à linha Core Visions.

## 1. O que Core Visions é

Core Visions não é apenas uma aparência visual. O material de origem define a proposta como **linguagem de pensamento**. A marca editorial combina:

- filosofia aplicada;
- psicologia;
- estética simbólica.

A função editorial é transformar:

**percepção → comportamento → identidade.**

A experiência prometida não é somente compreensão intelectual, mas reconfiguração.

## 2. Princípio de aplicação

A metodologia não deve ser aplicada automaticamente a todos os livros deste repositório.

Cada obra precisa registrar em sua ficha:
- CORE_VISIONS = SIM / NÃO / A DEFINIR;
- nível de aplicação;
- adaptações específicas;
- elementos que não devem ser importados.

Isso impede que uma identidade editorial transversal apague a voz particular de cada livro.

## 3. Tom de voz

O tom Core Visions combina quatro vetores:

### Clínico
Precisão, definição, corte conceitual, linguagem capaz de distinguir mecanismos.

### Filosófico
Reflexão profunda, formulação de perguntas fundamentais, elaboração de conceitos.

### Visionário
Criação de modelos novos, visão de futuro, formulações autorais.

### Direto
Pouca ornamentação gratuita, ausência de enrolação, recusa de romantização vazia.

### Teste do parágrafo
Cada parágrafo deve cumprir pelo menos uma função:
1. ensinar algo claro; ou
2. provocar ruptura perceptiva.

Se não fizer nenhuma das duas coisas, revisar.

## 4. Macroestrutura ritualística

### ATIVAÇÃO
Função:
- abrir com frase de impacto;
- quebrar expectativa;
- introduzir conceito central;
- criar tensão intelectual.

### DIAGNÓSTICO
Função:
- explicar o problema;
- desmontar crenças ou interpretações comuns;
- mostrar o mecanismo que mantém o leitor preso ao estado anterior.

### MODELO CORE
Função:
- apresentar teoria;
- transformar ideias em sistema;
- nomear componentes;
- tornar o modelo replicável;
- criar linguagem própria.

### RECONFIGURAÇÃO
Função:
- converter teoria em prática;
- propor exercícios mentais ou comportamentais;
- mostrar como o modelo altera decisões, percepção ou comportamento.

### INTEGRAÇÃO
Função:
- consolidar identidade;
- conectar o capítulo ao sistema maior;
- preparar a etapa seguinte;
- impedir que a ideia permaneça apenas como insight isolado.

## 5. Formato de capítulo

Quando adequado à obra:

1. frase de ruptura;
2. explicação direta;
3. conceito nomeado;
4. exemplo claro;
5. aplicação prática;
6. fechamento impactante.

Não impor este formato a capítulos históricos, narrativos ou documentais quando ele prejudicar a função da obra.

## 6. Nomenclatura

O material original enfatiza que conceitos relevantes devem receber nomes fortes e reutilizáveis.

Exemplos preservados:
- Sistema de Reconfiguração;
- Estado Base;
- Ruído Mental;
- Arquétipo Dominante;
- Fase de Integração.

Regra editorial:
- um nome deve condensar mecanismo real;
- não nomear apenas para parecer sofisticado;
- evitar excesso de termos que transformem o livro em glossário artificial;
- registrar definição, função, relação com outros termos e primeira ocorrência.

## 7. Estilo visual

### Paleta registrada
- Azul — visão, lógica.
- Preto/Branco — controle, domínio.
- Roxo — mistério, profundidade.

### Tipografia registrada
- títulos minimalistas, espaçados, frios;
- texto limpo e legível.

### Elementos gráficos
- diagramas mentais;
- símbolos quase místicos, mas racionais;
- respiro visual;
- seções com espaçamento amplo.

## 8. Linguagem

Priorizar:
- frases curtas e densas;
- impacto;
- baixa emotividade explícita com alta intensidade implícita;
- repetição estratégica de palavras-chave.

Evitar:
- motivação genérica;
- storytelling sem função;
- explicação longa sem retorno conceitual;
- superfície estética sem sistema intelectual.

## 9. Experiência do leitor

O projeto original busca produzir:
- clareza imediata;
- ruptura de percepção;
- aplicação prática;
- sensação de evolução interna;
- reconhecimento de que o texto fala diretamente com um problema real.

## 10. Frase guia

> Percepção cria realidade. Consciência cria controle.

## 11. Integração com o Processo de Abelha

Core Visions organiza a forma editorial. O Processo de Abelha organiza a criação.

Fluxo possível:
visão autoral → extração → beats intelectuais → arquitetura → definição de conceitos → teste Core Visions → redação → revisão → integração.

A metodologia editorial não substitui o cânone da obra.

## 12. Registro na base de dados

Cada livro que usar Core Visions deve ter campos:
- core_visions_aplicavel;
- core_visions_nivel;
- tom_predominante;
- estrutura_macro;
- conceitos_nomeados[];
- diagramas_previstos[];
- paleta;
- restricoes_visuais[];
- frase_guia_especifica;
- data_da_decisao;
- fonte_da_decisao.
