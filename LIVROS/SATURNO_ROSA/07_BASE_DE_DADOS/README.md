# BASE DE DADOS DE CRIAÇÃO — SATURNO ROSA
**Atualização:** 2026-10-17
**Versão:** 1.0

A base de dados é o **núcleo operacional** do tratado, não apenas um índice. Seu papel é preservar a origem, o estado e a genealogia de cada conceito, beat, símbolo, imagem, questão e atualização. A gravação de ideias organizadas não substitui transcrições brutas que ainda não estejam disponíveis. O esquema alinha-se com `BASE_DE_DADOS/NUCLEO_DA_BASE.md`, `NUCLEOS/MAGIA/BASE_DE_DADOS_DO_NUCLEO.md` e a metodologia autoral de Convenções de Realidade.

## Entidades
- **OBRA:** título, série, autor, meta, status, escopo, fonte e datas.
- **CONCEITO:** ID, enunciado, definição, status canônico, relações, proveniência.
- **CONVENÇÃO:** IDs SR-CR-001…036, tipo, descrição, origem, gravidade, núcleos, evidência, conflitos e histórico.
- **IDEIA-SÍMBOLO:** SR-IS-PARANOIA e SR-IS-PRONOIA, redes subordinadas, posição Rainha possível.
- **AGENTE:** Mãe Saturno, Pai Saturno, Criação Alquimista, Saturno Negro como estado/princípio, Saturno Rosa como manifestação ainda ontologicamente aberta.
- **OBJETO/LOCAL:** Titã, Maia, Cubo, Via Láctea, campo de contenção, cela, ventre, porta, símbolo hexagonal.
- **CAPÍTULO/BEAT:** estrutura, fundamento pregresso, mudança de estado, setup, payoff e datas.
- **FONTE:** autoria, data, nível factual, citação, arquivo original quando disponível.
- **IMAGEM:** ID, arquivo original, prompt, derivadas, versão, aprovação, direitos, hash, data.
- **PROMPT:** objetivo, conteúdo integral, versão, visuais de referência, resultados.
- **QUESTÃO:** problema, status, versões divergentes, impacto e decisão.
- **UPDATE:** diff conceitual, origem, data, arquivos afetados, aprovação.
