## Princípio visual

As Esferas não devem ser reduzidas automaticamente a sete bolas neon. O banco privilegia imagem conceitual capaz de mostrar função existencial, corpo, símbolo, psicologia, magia e dimensão coletiva.

## Registro futuro

Cada imagem deve receber, quando possível: image_id, Esfera, função editorial, descrição, prompt, restrições, referências, arquivo, status e datas de criação/aprovação.
