# Laboratório Criativo Samuel — Biblioteca e Base de Criação

**Autor:** Samuel Lucena da Silva  
**Última atualização:** 2026-10-16  
**Função:** arquivo mestre de livros, séries, tratados, teorias, romances, universos narrativos, imagens, prompts e genealogia criativa.

## Regra central

Este repositório não guarda apenas manuscritos. Ele funciona como **base de dados autoral de criação**.

> Samuel cria. A IA organiza.

A IA pode extrair, classificar, conectar, estruturar, comparar versões, apontar lacunas, pesquisar quando solicitado e preservar continuidade. Não deve preencher silenciosamente lacunas, transformar hipótese em fato, promover sugestão a cânone nem tornar uma ideia mais convencional apenas para parecer mais aceitável.

## Estrutura

- `CATALOGO_MESTRE.md` — índice geral das obras.
- `BASE_DE_DADOS/NUCLEO_DA_BASE.md` — modelo de dados, cânone, beats, convenções, updates.
- `LIVROS/NUCLEOS_DE_CRIACAO.md` — material descritivo recuperado das obras já trabalhadas no Laboratório.
- `IMAGENS_E_PROMPTS/BASE_VISUAL.md` — sistema visual, prompts, referências e arquivos.
- `HISTORICO/2026-10-16_UPDATE.md` — registro desta implantação.

## Datas e versões

Toda ficha deve carregar:
- data de criação conhecida, quando houver;
- primeiro registro conhecido;
- última atualização;
- estado de cânone;
- histórico de alterações.

Nunca apagar silenciosamente uma versão anterior. Registrar ANTIGO → NOVO → DATA → MOTIVO → APROVAÇÃO.

## Níveis de cânone

- **CONFIRMADO:** Samuel afirmou como parte do projeto.
- **PROVISÓRIO:** ideia em teste.
- **POSSIBILIDADE:** “talvez”, “poderia”, “pensei em”.
- **QUESTÃO ABERTA:** ainda não decidido.
- **SUGESTÃO DA IA:** nunca é cânone sem confirmação.

## Princípio

Organizar sem domesticar. Estruturar sem substituir. Registrar sem inventar. Desenvolver sem tomar a autoria.
